A single line from the Moon, finally answering back after billions of years of being stared at, wished on, and texted at 2 a.m.

> You keep texting 'you up?' at 2 a.m. like I have a choice. I've been up four billion years. Go to sleep.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/moon-out node main.ts
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
